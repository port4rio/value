# 実装計画: カードミニチャート表示・ヒートマップ調整・卒業生表示整理・プリセット改善

ユーザー様からの回答およびご要望に基づき、以下の改修を実施します。

---

## 1. 概要 & 背景

- **ミニチャートのカード表示**: 各銘柄カードの「銘柄名・株価ヘッダー」と「5大指標グリッド」の間に直近6ヶ月の株価ミニチャート（スパークライン）を表示。視覚的に値動きのトレンドを素早く比較できるようにします。
- **ヒートマップ色の反転・新規追加**:
  - **配当性向**: 低い方を黄緑グラデーション表示（増配余力・健全性）。テーブルとカードの両方に適用。
  - **PER / PBR**: 高い方を黄緑グラデーション表示（市場の評価・株価好調）。
- **卒業生銘柄名下のピンク文言削除**:
  - 一覧テーブルおよびカードで銘柄名下に表示されていた「PBR1.2倍超達成」などの文言を削除しすっきりした表示に。
  - 銘柄名クリック時の詳細モーダルには卒業理由・達成状況を引き続き明記。
- **クイックプリセットの改善**:
  - プリセットを「標準」と「王道バリュー」の2つに集約。
  - **王道バリュー条件**: 配当利回り ≧ 4.0%、PBR ≦ 1.2倍、ROE ≧ 8.0%、EBITDA成長率 ≧ +3.0%、自己資本比率 ≧ 50.0%
  - 複数回切り替えても確実に状態が更新されるよう、完全なオブジェクト置換方式で実装。

---

## 2. 変更対象ファイルと具体的な実装内容

### ① `src/types.ts`
- `OUDOU_VALUE_CRITERIA` 定数の追加:
  ```ts
  export const OUDOU_VALUE_CRITERIA: ScreeningCriteria = {
    minDividendYield: 4.0,
    maxPbr: 1.2,
    minRoe: 8.0,
    minEbitdaGrowth: 3.0,
    minEquityRatio: 50.0,
  };
  ```

### ② `src/utils/heatmap.ts`
- `payout_ratio`（配当性向）の評価方向を `'lower'`（低い方が良・黄緑）として定義・順位計算に追加。
- `per` の評価方向を `'lower'` から `'higher'`（高い方が良・黄緑）に変更。
- `pbr` の評価方向を `'lower'` から `'higher'`（高い方が良・黄緑）に変更。
- 上位12銘柄までの順位制グラデーション（緑〜黄緑系）を統一して算出。

### ③ `src/services/aiService.ts`
- 全銘柄のチャートデータを一括キャッシュする `fetchAllCharts()` 機構の追加。初回取得後は全カードが即座に同期してチャートを描画可能にします。

### ④ `src/components/StockCardList.tsx`
- **ミニチャート（スパークライン）**: 銘柄名行と5大指標の間にコンパクトなSVGミニチャート（直近6ヶ月）を描画。
  - 開始日〜直近の騰落に応じて、上昇（エメラルドグリーン系）/ 下落（マゼンタまたはニュートラル）のグラデーション線を適用。
  - 数値や目盛りは省略し、視覚的な形状比較に特化。
- **卒業生のピンク文言削除**: カード内の銘柄名下にある `graduationReason` の表示を削除。
- **指標スタイルの反映**: `payout_ratio` にヒートマップスタイル（低い方が黄緑）を適用。PER・PBRは高い方が黄緑になるスタイルが自動反映。

### ⑤ `src/components/StockTable.tsx`
- **卒業生のピンク文言削除**: 銘柄名下にあった `graduationReason` のテキストを削除し、テーブルの縦幅をコンパクトかつ均一に保ちます。
- **配当性向のヒートマップ化**: テーブルの「配当性向」セルに `getStockMetricStyle('payout_ratio', stock, metricRanks)` を適用（低い方が黄緑）。

### ⑥ `src/components/FilterModal.tsx`
- クイックプリセットを「標準」と「王道バリュー」の2ボタンに変更。
- 各ボタンクリック時に `setDraft({ ...DEFAULT_CRITERIA })` および `setDraft({ ...OUDOU_VALUE_CRITERIA })` をダイレクトに代入し、何度押しても確実にスライダーと入力値が正しく切り替わるよう修正。
- プリセットの説明テキスト（配当4.0%以上、PBR1.2以下、ROE8.0%以上、EBITDA+3%以上、自己資本50%以上）を明記。

## 3. 検証項目

1. **クイックプリセットの切替テスト**:
   - 「標準」→「王道バリュー」→「標準」と何度押しても各スライダー値が完全に切り替わること。
   - スクリーニング結果が王道バリュー条件（配当≧4.0%, PBR≦1.2, ROE≧8.0%, EBITDA≧+3%, 自己資本≧50%）に即座に絞り込まれること。
2. **ヒートマップ色の確認**:
   - PER / PBR が高い銘柄が黄緑にハイライトされていること。
   - 配当性向が低い銘柄が黄緑にハイライトされていること。
   - テーブルとカードの両方で色が一致していること。
3. **卒業生表示の確認**:
   - テーブルおよびカードで、銘柄名下のピンク色「PBR1.2倍超達成」が非表示になっていること。
   - 銘柄クリック後の詳細モーダルでは卒業理由が引き続き確認できること。
4. **カードミニチャートの確認**:
   - カード一覧ビューに切り替えた際、銘柄名と指標の間に直近6ヶ月のチャートが崩れず綺麗に表示され、形状の比較ができること。
5. **ビルド検証**:
   - `compile_applet` を実行し、TypeScript / Vite ビルドが正常に通ることを確認。
